# 鞘翅飞行拖尾特效

适用于 Minecraft 1.20.1 + Forge 47.4.0。

## 怎么玩

1. 把模组 jar 放进客户端和服务器的 `mods` 文件夹。
2. 穿上鞘翅开始滑翔，达到配置的速度后会出现拖尾。
3. 手持任意染料对空气点右键，就能把自己的拖尾改成该染料颜色；染料不会被消耗。
4. 周围安装了本模组的玩家会看到你的颜色、拖尾、星尘、水珠和残影。
5. 游戏内按 `K` 打开配置界面（按键可在"按键绑定"里修改）：左侧切换 视觉 / 音效 / 性能 / 触发条件 分类，所有改动立即生效并自动写回配置文件；联机到服务器时"触发条件"页为只读（由服务器决定）。

## 默认效果

- 滑翔速度超过 0.6 格/秒后显示拖尾。
- 同时显示流线飘带和翼尖双线；拖尾样式可选 尘埃（跟随染料颜色）、彩虹、烈焰、灵魂之火、星辉、附魔、电光、樱花。
- 星尘密度为 0.05。
- 雨天会出现更多气泡水珠。
- 每 0.5 秒留下一个粒子勾勒的身姿残影。
- 高速时播放随速度变化的风声，烟花推进开始时播放轰鸣。
- 每个客户端每刻最多生成 200 个本模组粒子；低帧率或游戏粒子设置降低时自动减半。

## 配置

首次启动后，Forge 会生成两个配置文件：

- 单人世界存档或服务器世界里的 `serverconfig/elytra_trails-server.toml`：服务器统一的生成条件，可选 `GLIDE`、`HIGH_SPEED`、`ROCKET_ONLY`、`CUSTOM`。
- 游戏目录 `config/elytra_trails-client.toml`：每位玩家自己的外形、星尘、水珠、残影、音效和性能选项。

`CUSTOM` 模式可以单独设置速度门槛，并选择是否必须在烟花推进期间才显示。
